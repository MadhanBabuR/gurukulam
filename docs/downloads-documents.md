# Downloadable documents

Files placed here are served from the site root under `/documents/`.
They are linked from the Downloads page (`downloads/index.html`).

Expected filenames (referenced by the Downloads page):

| File                          | Appears on the page as   |
|-------------------------------|--------------------------|
| `80g-certificate.pdf`         | 80G Certificate          |
| `csr-1-registration.pdf`      | CSR-1 Registration       |
| `fcra-registration.pdf`       | FCRA Registration        |
| `detailed-project-report.pdf` | Detailed Project Report  |
| `pitch-deck.pdf`              | Pitch Deck               |

Until a file is added, its entry on the Downloads page shows an
"Awaiting file" badge instead of a download button, so the page never
links to a missing file.
